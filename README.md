# ВДП

Разбор телеметрии скважин в браузере: забой и устье, пересчёт давления на верхние дыры перфорации, годовые замеры пластового давления, кривая восстановления давления и исследование на установившихся режимах.

## Как открыть

```bash
npm install
npm run dev
```

Приложение поднимается на порту 3847. Сразу открывается учебное месторождение — четыре скважины с января 2023 по ноябрь 2026, — чтобы графики и расчёты были видны без файла. Свой Excel заменяет набор.

Проверка методики:

```bash
npm test
```

## Файл Excel

Обязательные листы, имена можно писать с пробелами и в другом регистре:

| Лист | Что в нём |
| --- | --- |
| Рзаб | давление на глубине датчика |
| Тзаб | температура на глубине датчика |
| Руст | устьевое давление |
| Туст | устьевая температура |
| Расходомер | дебит |

Первый столбец — дата и время (`ДД.ММ.ГГГГ чч:мм` или дата Excel). Дальше по столбцу на скважину, имя скважины стоит в шапке. Пустая ячейка — это пропуск, не ноль.

Дополнительные листы: «Паспорт», «Пластовое давление», «КВД», «ГКИ». Пустой шаблон скачивается кнопкой «Шаблон».

Давление в файле может быть в МПа, атм, кгс/см², бар или psi, дебит — в м³/сут, тыс. м³/сут или м³/ч. На графиках всё приводится к МПа и м³/сут. Единицу можно поправить после загрузки в паспорте: пересчитаются телеметрия и замеры Рпл, журнал испытаний не трогается.

Данные остаются в браузере.

## Что считается

- Гидростатика между датчиком и верхними дырами. Для жидкости по плотности или заданному градиенту, для газа по `ρ = PM/(zRT)`. Предпочтительна вертикальная глубина.
- Депрессия и коэффициент продуктивности относительно годовых замеров Рпл.
- КВД: поиск остановок, график Хорнера, производная Бурде, проницаемость, скин, радиус исследования. Нефть и вода — по давлению, газ — по квадрату давления. Окно радиального притока можно сдвинуть.
- ГКИ: серии стабильных режимов, индикаторная диаграмма, прямая и Вогель для нефти, `a` и `b` и дебит абсолютно свободный для газа.
- Журнал официальных годовых КВД и ГКИ рядом с расчётом по телеметрии.
- Выбросы, залипший датчик, пропуски ряда, кроссплоты.

Формулы проницаемости сверены с полевыми уравнениями SPE и лежат во вкладке «Методика». Это разбор телеметрии, а не замена специализированной интерпретации испытания.
